# SWYNEX Task 2 - Machine Learning Model

## Project Overview
This project focuses on training and evaluating machine learning models using the Titanic dataset to predict passenger survival.

## Dataset
Titanic Passenger Dataset.

## Machine Learning Models
1. Logistic Regression
2. Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Load the preprocessed dataset.
2. Separate input features and target variable.
3. Train Logistic Regression.
4. Train Random Forest.
5. Evaluate both models.
6. Compare model performance.
7. Identify the better-performing model.

## Conclusion
Both models were successfully trained and evaluated. Their performance was compared using multiple evaluation metrics to identify a suitable model for Titanic passenger survival prediction.
